# Подсчёт подходящих элементов

**Задача:** посчитать, сколько чисел в списке больше заданного порога.

```python
numbers = [2, 7, 4, 9, 1]
limit = 5
count = 0

for number in numbers:
    if number > limit:
        count += 1

print(count)
```

Результат — `2`, потому что условию соответствуют числа `7` и `9`.

- [[Числовые типы данных]] нужны для хранения элементов и порога.
- [[Условный оператор]] проверяет `number > limit`.
- [[Циклы]] перебирают все элементы списка.

Задача похожа на [[Сумма положительных чисел]], но вместо сложения значений увеличивается счётчик.
