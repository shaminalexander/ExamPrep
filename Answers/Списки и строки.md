# Списки и строки

Список хранит несколько значений в одном объекте. К элементам можно обращаться по индексу, а цикл позволяет обработать их по очереди.

Строка — это последовательность символов. Число `25` и строка `"25"` выглядят похоже, но имеют разные типы: число участвует в арифметике, строка хранит текст.

Пример:
```python
numbers = [3, -2, 0, 5]
text = "25"
number = 25
```

**Связь с задачами:** список является входными данными для [[Сумма положительных чисел]] и [[Подсчёт подходящих элементов]].
