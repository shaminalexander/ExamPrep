# Сумма положительных чисел

**Задача:** дан список целых чисел. Нужно сложить только положительные элементы.

Для списка `[3, -2, 0, 5]` ответ равен `8`.

```python
numbers = [3, -2, 0, 5]
total = 0

for number in numbers:
    if number > 0:
        total += number

print(total)
```

- [[Числовые типы данных]] помогают выбрать тип для элементов и суммы.
- [[Условный оператор]] проверяет, что число больше нуля.
- [[Циклы]] позволяют перебрать весь список.
- Общий термин [[Цикл]] хранится в словаре, а не копируется в каждый ответ.

Если положительных элементов нет, сумма остаётся равной `0`.
