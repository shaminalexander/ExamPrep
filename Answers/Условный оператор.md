# Условный оператор

Условный оператор `if` выбирает, какой блок кода выполнить, в зависимости от результата логического выражения. Если условие истинно, выполняется первая ветвь; иначе может выполниться `else`.

Общий термин: [[Логическое выражение]].

Пример:
```python
number = 5
if number > 0:
    print("Положительное")
else:
    print("Не положительное")
```

**Связь с задачами:** в [[Сумма положительных чисел]] условие `number > 0` позволяет складывать только положительные элементы. В [[Подсчёт подходящих элементов]] условие определяет, какие значения учитывать.
