# Циклы

Цикл повторяет блок действий. В Python `for` обычно перебирает элементы последовательности, а `while` повторяет действия, пока условие истинно.

Общий термин: [[Цикл]].

Пример:
```python
for number in [3, -2, 0, 5]:
    print(number)
```

Цикл нужен, когда требуется обработать каждый элемент списка. Например, он используется в [[Сумма положительных чисел]] и [[Подсчёт подходящих элементов]].
