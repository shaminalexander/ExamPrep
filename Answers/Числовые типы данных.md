# Числовые типы данных

Числовой тип определяет, какие числа можно хранить и какие операции с ними выполнять. Для целого количества обычно подходит `int`, а для дробных значений — `float` (в Python).

Общий термин: [[Тип данных]].

Пример:
```python
count = 12
price = 15.5
```
`count` хранит целое число, а `price` — дробное. При решении задачи о сумме важно выбрать тип, который подходит для исходных значений и результата.

**Связь с задачами:** перед решением [[Сумма положительных чисел]] нужно понять, какие значения хранятся в списке и какого типа будет сумма.
