# Проверка ответа товарища

Проверяемый материал: [[Сумма положительных чисел]].

Маршрут проверки: карта «[[Подготовка к экзамену]]» → ответ → общий термин «[[Цикл]]» → обратно к ответу.

Наблюдение: пояснения показывают, зачем в задаче нужны числовой тип, условие `number > 0` и цикл. Пример `[3, -2, 0, 5]` даёт сумму `8`. После проверки можно изменить статус ответа с `review` на `approved`.

*Заполнить фактическим именем проверяющего после реальной проверки.*
