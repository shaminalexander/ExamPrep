# ExamPrep — подготовка к экзамену по программированию

## Вопросы и ответственные
Для учебного примера используются условные участники. Перед сдачей заменяю их на реальные имена команды.

| № | Вопрос | Ответственный |
|---|---|---|
| 1 | Числовые типы данных | Участник A |
| 2 | Списки и строки | Участник A |
| 3 | Условный оператор | Участник B |
| 4 | Циклы | Участник B |
| 5 | Сумма положительных чисел | Участник C |
| 6 | Подсчёт подходящих элементов | Участник C |

Проверка: автор готовит ответ, другой участник проверяет содержание и ссылки. Только после проверки статус меняется на `approved`.

## Структура
- `Answers/` — ответы на экзаменационные вопросы.
- `Terms/` — общий словарь терминов.
- `Decisions/` — результаты проверки и согласованные решения.
- `Подготовка к экзамену.md` — карта содержания (MOC).

## Правила
- `type`: `answer` или `term`.
- `status`: `draft`, `review` или `approved`.
- `owner`: единое написание имени ответственного.
- Определение термина хранится один раз в `Terms/`; ответы ссылаются на него.
- Перед `pull` проверяю `git status`; перед коммитом — `git diff`.
- Не использую `force push` для решения конфликтов.
