# Тип данных

**Определение:** тип данных определяет множество значений, которые может хранить объект, и допустимые операции над ними.

**Источник:** официальная документация Python, встроенные типы: https://docs.python.org/3/library/stdtypes.html

**Пример:** `int` хранит целые числа, `float` — числа с дробной частью.

Используется в ответе [[Числовые типы данных]] и задаче [[Сумма положительных чисел]].
