# Цикл

**Согласованное определение:** цикл повторяет блок действий. Цикл `for` перебирает элементы последовательности. **Цикл while повторяет действия, пока условие истинно.**
**Согласованное определение:** цикл повторяет блок действий. Цикл for используется для перебора элементов последовательности.

**Источник:** официальная документация Python: https://docs.python.org/3/tutorial/controlflow.html

**Пример:** `for number in numbers:` последовательно получает элементы списка.

Термин используется в [[Циклы]] и [[Сумма положительных чисел]]. После уточнения определения оба ответа нужно перечитать и проверить на соответствие.
