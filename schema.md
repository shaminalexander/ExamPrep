# Схема свойств базы

| Свойство | Допустимые значения | Назначение |
|---|---|---|
| `type` | `answer`, `term` | Отличает экзаменационный ответ от общего термина |
| `status` | `draft`, `review`, `approved` | Показывает готовность материала |
| `owner` | Участник A / Участник B / Участник C | Показывает ответственного |

**Порядок проверки:** автор создаёт заметку со статусом `draft`; затем передаёт её товарищу и ставит `review`; проверяющий проверяет объяснение, пример и ссылки. Только после исправлений статус меняется на `approved`.

Для всех заметок используется одинаковое написание `owner`.
