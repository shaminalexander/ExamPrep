# Подготовка к экзамену

## Маршрут повторения

1. [[Числовые типы данных]] — сначала выбираю подходящий тип для исходных значений и суммы.
2. [[Списки и строки]] — понимаю, как хранится набор значений и чем число отличается от текста.
3. [[Условный оператор]] — учусь проверять, подходит ли элемент условию.
4. [[Циклы]] — перебираю все элементы списка.
5. [[Сумма положительных чисел]] — объединяю тип данных, условие и цикл в одной задаче.
6. [[Подсчёт подходящих элементов]] — использую похожий перебор, но вместо суммы увеличиваю счётчик.

## Общий словарь

- [[Логическое выражение]]

Задача о сумме полезна после повторения числовых типов, условий и циклов: сначала выбирается тип суммы, затем проверяется положительность каждого элемента, после чего цикл обрабатывает весь список.
